How these tests are carried out

  1. Compile: ./gradlew testDebugUnitTest builds the app + 23 test files with JDK 17 / Android SDK 36.
  2. Runtime: each test executes under Robolectric — real Android classes (Context, MediaStore, SQLite, accessibility models) provided in-process, fully repeatable, no device required.
  3. Assertion: every test is a hard assertion; any failure fails the whole build (CI can't go green while red).
  4. Evidence: the runner writes one XML result file per suite (name · class · time · outcome · failure-trace-if-any). This page is generated by reading those XML files directly — nothing hand-typed, and failure messages would be shown verbatim if any existed today.
  5. Device layer (separate): real Android 16 runtime via adb — install, launch, foreground checks, screenshots, crash-log audit, MediaStore scan of pushed PDFs (the Nano data path), NanoGate probe truth. Logged in EXECUTION-LOG-VERBATIM.md.
